# ADR-0001 — Modular monolith, not microservices

- **Status:** Accepted (2026-09-03, with Z-1)
- **Deciders:** Owner, architecture
- **Related:** [ADR-0009](ADR-0009.md) (runtime roles), architecture §0, §55

## Context

Flower SaaS spans ~31 domains (identity, catalog, inventory, orders, payments,
accounting, cash-register, workforce, AI, …) for a modest number of tenants at
launch. The team is small. Cross-domain transactional integrity is a hard
requirement (a sale writes order + payment allocation + journal entry + inventory
movement + outbox row **atomically**).

## Decision

Build a **modular monolith**: one TypeScript codebase, one deployable image, run in
four **runtime roles** (`api`, `worker`, `scheduler`, `realtime` — see ADR-0009).
Domains are NestJS modules with their own service layer and tables. Modules
communicate through **service interfaces and domain events**, never by touching
another module's repositories — enforced by ESLint boundary rules
(`eslint-plugin-boundaries` + a custom rule). One PostgreSQL database. No
service-to-service network calls for core business flows. No Kubernetes.

## Consequences

- **Positive:** atomic multi-domain transactions are trivial; one migration history;
  one deployment; local dev is `docker compose up`; refactoring across module
  boundaries is a compiler-checked operation.
- **Negative:** all roles scale together at the process level (mitigated by separate
  runtime roles that scale independently); a bad module can affect the whole process
  (mitigated by boundary lint, tests, and per-queue isolation in the worker).
- **Enforcement:** module-boundary lint rule is a CI gate from Phase 0 (Task 0.2),
  with a negative test fixture that must fail lint.

## Alternatives considered

- **Microservices** — rejected: premature for the tenant count and team size;
  turns every atomic financial write into a distributed-transaction problem.
- **Serverless functions** — rejected: cold starts, connection-pool pressure on
  Postgres, and no natural home for the outbox dispatcher / realtime gateway.
