### How to do it without risk (when you authorise a commit — none was made)

1. Re-verify the snapshot: `sha256sum -c files-before.sha256` against the preserved archive (edited files will differ — the list of files edited this session is in the report).
2. For each PR: `git switch -c phase-<n>/<slug> origin/main`, add **only** that PR's paths, run the repo gate (`pnpm -r build`, `pnpm -r test`, lint, the S-1 check), commit with
   the CLAUDE.md trailer, open the PR from the branch. Never force-push, never rewrite history (CLAUDE.md rule 37).
3. After each merge, rebase the next branch **forward** (a new merge-from-main commit, not a history rewrite).
