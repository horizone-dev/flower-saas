## 5. The one conflict: resolution recipe (step 5)

Merging `main` (with the baseline) into #44's branch stops on two files and nowhere else:

1. `apps/owner-web/package.json`: take #44's file and set `"next": "16.4.6"` (it carries `"16.4.1"`); keep #44's `qrcode-generator` `2.0.4` and `jsqr` `1.4.0`.
2. `pnpm-lock.yaml`: take `main`'s file, then run `pnpm install --lockfile-only` (a regenerated lockfile is canonical; the recipe was run exactly this way).
3. Check: `pnpm install --frozen-lockfile` succeeds, and the merged tree equals the #55 tree plus the baseline's `package.json` override line and lockfile (§4). Any other conflicting file means the recipe does not apply: stop and report.
