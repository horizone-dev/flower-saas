Pilot stock stance (was: availability-only).** The Owner can switch a product on/off per branch. **Not provided:** quantities, deduction on sale, receiving, counts, valuation, COGS, profit, stock-based availability — **there is no automatic inventory support**; overselling is possible and stock is controlled outside the system. Reports are _invoiced sales_, not profit. Refunds are operator-assisted (no screen). Sales are **online-only** (Rule 31): if the API or network is down the shop uses the paper log; nothing is entered retroactively without an owner decision. Automatic inventory = both approved costing methods, locked at setup, accountant-approved: a separate ≈ 23–30-day delivery; the quantity-only ledger is **not** a substitute and stays unapplied.

**Order of application after approval:** R-1 + F-1 migration + F-6 + M-1 together → full regression → browser rehearsal on the migrated schema → F-7 route A with its tests → CI green → staging host → gates (restore drill on a separate host, printer sheet, rollback rehearsal, independent security review).
