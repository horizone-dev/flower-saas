## 3. Rules that make the result trustworthy

1. The sheet above is **approved in writing before the first run**; the approved copy is archived with the report.
2. **No criterion is changed after a result is seen.** A failed run is reported and diagnosed, never discarded.
3. **Every repetition is reported**; a criterion is judged on the **worst** repetition.
4. The benchmarked build is the build **the closure branch's own CI verified** (git SHA recorded).
5. The environment, dataset fingerprint and driver version are part of the report; a result is valid only for them.
6. **No capacity claim** is made from a local number, and none from a single rate.
