# Testing strategy

> Architecture §54. **No test is silently skipped.** DB / security / isolation
> checks run **locally before commit**, not deferred to CI-only. Green states only
> on `main`.

## Runners & infra

- **Vitest** for unit + integration + component. **Testcontainers** (`packages/testing`)
  spins Postgres 17 + Redis 7 + MinIO for integration/e2e. **Playwright** for web
  e2e (later phases). **k6** for load (later phases).
- `packages/testing` provides: the Testcontainers bootstrap, `withTenantContext(...)`,
  the tenant + branch **probe-suite harness**, and concurrency-test utilities
  (parallel-request helpers, deterministic clocks).

## Rules

- A skipped test fails CI unless it carries a `// SKIP(<ticket>): <reason>` and the
  count of skips is reported. A quarantined flaky test is tracked and time-boxed.
- Isolation, financial and concurrency suites are **build-blocking** from the phase
  that introduces them.
- Tests use `packages/testing` fixtures — no hand-rolled tenants/branches per test
  file.
- No network calls to real external providers in CI — adapters have contract tests
  against recorded fixtures / a local fake.
- Coverage is a signal, not a gate; the isolation/financial/concurrency suites are
  the real gate.
